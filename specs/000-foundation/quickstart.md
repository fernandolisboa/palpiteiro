# Quickstart

## Local Setup

1. Ensure Node 24 is active
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:3000`

## Validation

- `npm run lint`
- `npm run typecheck`
- `npm run test`
- `npm run build`

## Demo Mode

If no environment variables are configured, the application serves mock fixtures
and mock analyses so the shell can still be explored.
