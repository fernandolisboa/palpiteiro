# Research Notes

## UX Direction

- Preserve the green-on-deep-evergreen energy from the Stitch exploration
  without reproducing heavy card mosaics.
- Favor large fixture rows, confident typography, and compact signal strips.
- Keep provider comparison visual, but derived from real contracts instead of
  free-form HTML prototypes.

## Technical Direction

- Render main pages as server components where possible.
- Keep interactive analysis selection in a dedicated client component.
- Route handlers should return the same types consumed by the UI.
- Demo mode must be deterministic so screenshots and tests remain stable.
