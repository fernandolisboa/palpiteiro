# Quickstart

## Explore The Shell

1. Run `npm install`
2. Run `npm run dev`
3. Visit `/`
4. Open a fixture from the list
5. Open `/analysis/<fixtureId>` and generate a demo analysis

## API Smoke Checks

- `GET /api/fixtures`
- `GET /api/fixtures/:fixtureId`
- `POST /api/analyses`
- `GET /api/ranking`
- `GET /api/history`
